## Citation and reproducibility

Project repository `[GITHUB_URL]`. Archival DOI `[DOI]`. Suggested citation: R. Cooperman and A.E. Petrunina V.V., *The Physical Clock under Spatial Blocking in SU(N) Lattice Yang–Mills*, XISOSIS, Vienna, 22 November 2026, first draft. DOI `[DOI]`.

From the extracted directory, `sha256sum -c SHA256SUMS` checks the distribution. To repeat the mathematics and numerical tests, follow `W2aR/README.md`. `W2aR/records/w2ar-v1/checks.out` records the licensed replay. `W2aR/records/w2ar-v1/final.local.out` contains the local Lean output. The original mathematical freeze is independently checked in its historical byte representation. The licensed packet has a distinct file digest. The historical attachment-review directory records the earlier edition.
